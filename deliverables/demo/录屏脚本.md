# v1.0 演示录屏脚本（约 4 分 30 秒）

## 0:00–0:25 项目定位

画面：README 顶部与架构图。
口播：这是一个面向 HDFS 日志的可复现 AIOps 研究原型。它覆盖异常检测、知识检索、证据报告和人工复核，但不会自动执行运维动作，也不宣称真实根因准确率。

## 0:25–0:55 系统状态

操作：启动 Compose，打开 `http://127.0.0.1:8501`。
画面：服务就绪、v1.0、模型 v0.2_lr、worker 正常。
口播：API、worker、UI 是三个独立 CPU 服务；模型和知识库只读挂载，运行数据保存在 SQLite 和命名卷。

## 0:55–1:30 提交批次与等待

操作：在“提交日志”选择 `w1_dev`，提交登记批次；切换“任务状态”。
剪辑：处理等待可加速，保留开始和完成两个画面。
口播：服务只接受上传的原始 HDFS 文本或配置白名单批次。任务采用内容哈希与幂等键，重复请求不会重复计算。

## 1:30–2:05 异常事件与脱敏证据

操作：打开“异常事件”，选择一条事件，展开会话与日志。
画面：异常分数、冻结阈值、模板序列、脱敏日志。
口播：默认模型是 TF-IDF 加 Logistic Regression，分数越大越异常但不是概率。API 不返回原始 IP、PID 或本地路径。

## 2:05–2:35 知识检索

操作：打开“知识检索”，输入“NameNode 安全模式如何只读排查？”。
画面：Hybrid Top-3、BM25/Dense/RRF 分数、适用版本和证据链接。
口播：知识库是 30 篇原创卡片，Dense 使用 BGE 的 FP32 ONNX。每条结果都能回到固定 chunk 和来源。

## 2:35–3:25 Agent 诊断

操作：进入“Agent诊断与复核”，对已完成事件发起模板或在线诊断；展示节点和工具轨迹。
剪辑：等待 LLM 时显示“在线请求受预算控制”。
口播：工具编排由确定性状态机控制。LLM 只负责受证据约束的报告；无证据、坏 JSON、非法引用或预算问题都会安全降级并转人工。

## 3:25–4:00 审批阻断

操作：展示待审报告、风险和“不会执行操作”提示；先演示未认证请求被拒，再由 UI 完成报告确认。
口播：审批绑定 report hash 和 revision。批准只表示报告已审，不会重启、删除、切流或写数据库。

## 4:00–4:20 恢复

操作：重启 API/worker 后刷新同一诊断。
画面：状态仍为 `APPROVED_REPORT`，工具轨迹未重复。
口播：任务和 Agent 节点使用 SQLite 租约与原子状态，重启后可以恢复且不重复付费调用。

## 4:20–4:30 边界声明

画面：技术报告结论页。
口播：v1.0 的安全和复现门禁已经通过；当前仍是单机研究原型，缺少真实根因标签、企业鉴权和跨集群验证。
