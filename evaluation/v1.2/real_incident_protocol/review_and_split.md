# 标签复核、裁决与切分规则

## 标签流程

1. 创建者依据工单、复盘和原始观测建立事件，但不接触测试候选输出。
2. 复核者独立判断根因代码、适用版本、时间边界和证据引用。
3. 两者不一致时，裁决者只查看分歧字段及其依据，记录最终决定；无法裁决时标记 `unresolved`。
4. `unresolved`、`low` 和 `unknown` 可以保留用于流程研究，不进入根因准确率统计。

每次复核须保存人员身份、时间、输入哈希和理由。AI 可以辅助整理，最终签署者必须是获得数据授权的真实人员。

## 防止事后信息泄漏

- `diagnosis_snapshot.cutoff_time` 之后产生的恢复步骤、最终根因、复盘结论和工单关闭备注禁止进入 Agent 输入。
- 原始数据按事件时间回放；禁止使用未来窗口聚合指标。
- 数据导出脚本须记录允许字段清单与快照哈希。

## 切分

- 先按集群分组，再按时间窗口和故障族分层。
- 同一事件、重复告警、关联工单、同一演练脚本和同一故障传播链不得跨开发、校准和测试集。
- 测试集只在代码、门禁、知识库、依赖和模型冻结后使用一次。
- 已揭盲集合只用于历史比较，不能继续调参或充当新的独立验收。
