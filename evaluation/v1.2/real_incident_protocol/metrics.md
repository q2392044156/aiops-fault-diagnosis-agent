# v1.2 指标计算规范

## 根因排序

- **Top-1**：第一候选与最终根因代码一致的事件比例。
- **Top-3**：前三候选至少一个与最终根因代码一致的事件比例。
- **MRR**：最终根因首次出现名次的倒数均值；未出现记 0。
- 仅统计 `confirmed` 或 `high` 标签；其余返回 `N/A` 并报告排除数量。

## 误报

- 以复核后确认无故障或不属于目标故障族的事件为分母。
- 同一事件窗口内的重复告警先按协议去重，不能重复增加分母或分子。

## 检测时延

- `MTTD = agent_detected - fault_start`。
- 同时报告 `agent_detected - first_observable_signal`，用于区分观测延迟与算法延迟。
- 所需时间戳缺失、时区不明、来源不一致或出现负时延时，该事件不进入统计并返回 `N/A`。
- 汇总至少报告样本数、中位数和 P95；样本过少时只报告逐例值，不承诺总体性能。

## 缺失值

没有合格根因标签时，Top-1、Top-3、MRR 为 `N/A`。没有合格时间戳时，MTTD 为 `N/A`。不得用 HDFS block 异常标签、模型异常分数或人工猜测填充。
