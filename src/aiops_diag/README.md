# 核心包

## 模块职责

统一暴露项目版本和顶层功能域。

## 依赖边界

顶层包只定义公共元数据，不反向依赖具体业务模块。

## Python 文件说明

| 文件 | 主要功能 | 主要类或函数 |
| --- | --- | --- |
| `__init__.py` | 定义当前包的公共入口、版本或导出符号。 | — |
| `common.py` | 提供跨流程共享的哈希、路径、JSON 和配置工具。 | `digest`、`canonical`、`save`、`config_root` |

## 阅读建议

先阅读配置或 Schema，再阅读核心引擎，最后查看 `workflow.py`、`__main__.py` 或验收脚本了解完整调用顺序。文件内的中文注释重点解释职责、输入参数、数据字段和关键约束。
